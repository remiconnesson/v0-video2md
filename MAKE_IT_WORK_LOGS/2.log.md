## Issue

## Analysis
The errors `Type mismatch` suggest that `youtubei.js` is struggling to parse the response from YouTube. This often happens when YouTube changes their internal API structure (InnerTube).
Resulting `info` object seems to be incomplete or broken, as `Got metadata for: undefined` suggests `info.basic_info.title` or similar might be missing.
The fallback `getTranscript()` also fails.

## Plan
1. Investigate `lib/fetch-and-save-transcript.ts` and how `youtubei.js` is instantiated.
2. Check if we need to update `youtubei.js` or adjust the configuration.
3. Repro the issue with a test script.
